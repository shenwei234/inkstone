# InkStone 宝塔面板部署教程

> 环境：Ubuntu 20.04/22.04 + 宝塔面板 + Docker Compose + 自有域名
> 架构：宝塔 Nginx（80/443 + SSL）→ 127.0.0.1:3000（前端）/ 127.0.0.1:8080（API）
> 全程约 15 分钟。

---

## 一、准备：安装 Docker 与镜像加速

### 1.1 安装 Docker（宝塔内）

面板左侧「软件商店」→ 搜索 **Docker** → 安装「Docker管理器」。

安装完成后在「终端」里验证：

```bash
docker --version
docker compose version
```

### 1.2 配置镜像加速（国内服务器必做）

宝塔「Docker管理器」→ 设置 → **镜像加速**（或编辑 `/etc/docker/daemon.json`），填入：

```json
{
  "registry-mirrors": ["https://docker.m.daocloud.io", "https://docker.1ms.run"]
}
```

保存后重启 Docker：

```bash
systemctl restart docker
```

## 二、上传代码

### 方式 A：用 Git（服务器能访问 GitHub 时）

```bash
mkdir -p /www/wwwroot && cd /www/wwwroot
git clone https://github.com/shenwei234/inkstone.git
cd inkstone
```

> 国内服务器拉 GitHub 慢/失败时：用 Gitee 镜像，或直接用「方式 B」。

### 方式 B：上传压缩包（推荐国内服务器）

1. 本地把 `inkstone-v1.2.0.zip` 上传到 `/www/wwwroot/`
2. 面板「文件」→ 右键压缩包 → **解压** 到 `/www/wwwroot/inkstone`
3. 终端进入目录：

```bash
cd /www/wwwroot/inkstone
```

---

## 三、配置环境变量

```bash
cp .env.example .env
```

面板「文件」→ 打开 `/www/wwwroot/inkstone/.env`，修改为（把 `blog.example.com` 换成你的域名）：

```ini
DB_USER=blog
DB_PASSWORD=换成强密码
DB_NAME=blog_platform

# 生成方式：openssl rand -hex 32
JWT_SECRET=粘贴生成的64位随机字符串

FRONTEND_URL=https://blog.example.com
PUBLIC_API_URL=https://blog.example.com
NEXT_PUBLIC_API_URL=https://blog.example.com/api/v1
```

> ⚠️ 三个 URL 必须与最终访问的域名**完全一致**（`NEXT_PUBLIC_API_URL` 是构建期注入，改了域名必须重新 build）。

生成密钥：

```bash
openssl rand -hex 32
```

## 四、构建并启动

```bash
cd /www/wwwroot/inkstone
docker compose -f docker-compose.baota.yml up -d --build
```

首次构建约 3~6 分钟（已内置 goproxy.cn / npmmirror 国内源）。

查看状态：

```bash
docker compose -f docker-compose.baota.yml ps
curl http://127.0.0.1:8080/healthz     # 期望 {"status":"ok"}
curl -I http://127.0.0.1:3000          # 期望 HTTP/1.1 200
```

两个都正常后继续下一步。

## 五、解析域名 + 建站 + SSL

### 5.1 域名解析

到域名商（阿里云/腾讯云）添加 A 记录：`blog.example.com` → 服务器公网 IP。

同时在**阿里云安全组**放行 `80`、`443`（34655 面板端口保持开放）。

### 5.2 宝塔建站

面板「网站」→ 添加站点：

- 域名：`blog.example.com`
- 根目录：随便（会做反向代理，不用放文件）
- PHP 版本：纯静态

### 5.3 申请 SSL

站点 → 设置 → **SSL** → Let's Encrypt → 申请 → **强制 HTTPS** 打开。

### 5.4 配置反向代理

站点 → 设置 → **反向代理** → 添加反向代理：

- 代理名称：`inkstone`
- 目标 URL：`http://127.0.0.1:3000`
- 发送域名：`$host`

保存后，点该代理的「配置文件」，把内容替换为下面这份（关键是 `/api/v1/` 与 `/uploads/` 转发到 8080）：

```nginx
location ~ ^/(api/v1|uploads)/ {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    client_max_body_size 20m;
}

location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

保存 → 重载 Nginx。

## 六、初始化站点

浏览器访问 `https://blog.example.com`：

## 七、日常运维

### 更新版本

```bash
cd /www/wwwroot/inkstone
git pull                                   # 或重新上传覆盖源码
docker compose -f docker-compose.baota.yml up -d --build
# 数据库结构变更会在后端启动时自动迁移
```

### 数据备份

```bash
cd /www/wwwroot/inkstone
# 数据库
docker exec inkstone-postgres pg_dump -U blog blog_platform > backup_$(date +%F).sql
# 上传的图片
docker run --rm -v inkstone_uploads_data:/data -v $(pwd):/backup alpine \
  tar czf /backup/uploads_$(date +%F).tar.gz /data
```

### 恢复数据库

```bash
cat backup_2026-01-01.sql | docker exec -i inkstone-postgres psql -U blog blog_platform
```

### 查看日志

```bash
docker compose -f docker-compose.baota.yml logs -f backend
docker compose -f docker-compose.baota.yml logs -f frontend
```

## 八、常见问题

| 问题 | 解决 |
|---|---|
| 拉取 `postgres:16-alpine` 超时 | 未配镜像加速 → 见 1.2 |
| 构建很慢 | 已在 Dockerfile 内置国内源；如仍慢检查服务器带宽 |
| 页面打不开、API 报 CORS | `.env` 三个 URL 与访问域名不一致；改后必须 `up -d --build` 重新构建前端 |
| 上传图片无法显示 | Nginx 缺少 `/uploads/` 转发 → 见 5.4 |
| 端口被占用 | `lsof -i:3000` / `lsof -i:8080` 排查 |
| 忘记管理员密码 | 见下方 SQL 重置 |
| 想让普通用户也能发文章 | 后台「用户管理」把角色改为管理员，或后续版本开放作者角色 |

重置管理员密码为 `password123`：

```bash
docker exec -it inkstone-postgres psql -U blog -d blog_platform \
  -c "UPDATE users SET password_hash='\$2a\$10\$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy' WHERE email='你的邮箱';"
```

## 九、安全建议

1. **修改宝塔面板默认信息**：面板设置 → 改强密码 + 开启二次验证 + 绑定域名/IP 白名单
2. 不要对外暴露 `5432`（数据库）、`3000`、`8080`（本编排已只绑定 127.0.0.1）
3. 定期备份数据库与上传目录
4. 面板「安全」→ 放行必要端口即可（80/443 + 面板端口）
